# Keyphrase vocabulary construction

Create a vocabulary of keyphrase from a collection of texts


## Steps overview

+ Keyphrase extraction of ERU-KG: `keyphrase_extraction/`
+ Group similar keyphrases: `keyphrase_grouping/`
+ Build keyphrase vocabulary: `keyphrase_vocab_build/`
+ Integrate keyphrase vocabulary into BERT: `keyphrase_vocab_integration/`
